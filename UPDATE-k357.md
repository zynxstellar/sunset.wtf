# Rift k357

Car Kill All selects the nearest eligible enemy to the car, skips seated players, and retains its ten-second timeout. Enables Car Noclip during operation and restores it on disable if automatically enabled. Descends twelve studs below the lower car/target height, flies underneath toward the next target, then rises nearby for a ram pass. Native car collisions restore only near the ram target. Fixed speed 100 km/h, converted using 0.28 meters per stud.

Local tests cover nearest selection, descent/cruise/rise, bounded speed and cleanup. Terrain depth is estimated from car/target height, not measured underground terrain. Live collision damage and server acceptance are unverified.
